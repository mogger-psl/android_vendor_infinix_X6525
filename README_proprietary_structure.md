Se han creado archivos .gitkeep para forzar el versionado de la siguiente estructura de directorios bajo "proprietary":

- proprietary/
  - system/
    - bin/
    - lib/
    - lib64/
    - etc/
  - vendor/
    - bin/
    - lib/
    - lib64/
    - etc/
    - firmware/
  - product/

Cada directorio contiene un archivo .gitkeep. Añade aquí tus binarios o archivos propietarios según corresponda.
